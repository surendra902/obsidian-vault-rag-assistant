# Getting Things Done

David Allen's system. The insight underneath it: **your mind is for having ideas, not holding them.** Every untracked commitment occupies background attention ("open loops"); writing every one into a trusted external system is what produces the "mind like water" state.

## The five steps

1. **Capture** — everything into inboxes. If it might matter, it's in the system or it doesn't exist.
2. **Clarify** — per item: what is it? Is it actionable? What's the very next physical action?
3. **Organize** — next actions onto lists by context, projects get a list each, someday/maybe and reference filed. Trash the rest.
4. **Reflect** — the weekly review, where lists are trusted again or the system rots. See [[weekly-review]].
5. **Engage** — choose by context, time available, energy, priority. In that order.

## The two rules with the highest torque

- **The two-minute rule**: if an action takes less than two minutes, do it now. Tracking it costs more than doing it.
- **Next physical action**: define tasks as verbs ("draft the intro," not "report"). Vague items are where projects go to die, because every glance at "report" triggers a re-decision.

## Where it fits

GTD handles commitments; PARA ([[para-method]]) is essentially its filing layer scaled to notes. The capture habit is the same one [[zettelkasten]] calls fleeting notes. Allen's system is strongest at "nothing forgotten" and weakest at "what matters most" — priorities still need the review.
